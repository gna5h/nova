# Nova — Data Analyst AI Dev Assistant

> A web app that automates the repetitive parts of data analysis: profiling, cleaning, aggregation, statistical testing, and reporting.

![Python](https://img.shields.io/badge/Python-3.12-blue) ![FastAPI](https://img.shields.io/badge/FastAPI-latest-green) ![Next.js](https://img.shields.io/badge/Next.js-15-black) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)

Users either **ask in plain language** and the AI builds a step-by-step plan, or **use the guided wizard** directly. Each step returns an output: a cleaned file, a result table, a test result, or a report.

**Status:** Milestone 0 — skeleton (see [roadmap](docs/ARCHITECTURE.md#14-roadmap))
